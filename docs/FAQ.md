# FAQ

## Is this for real clinical care?

No. It is an educational simulator only.

## Why are the calculations simplified?

The model is designed to provide consistent training feedback when settings change. It is not a validated physiologic model.

## Why are raster patient images blocked?

The patient is rendered as SVG so state changes, accessibility labels, bundle budgets, and visual regression screenshots stay controllable.

## How do I inspect performance?

Run `npm run check:performance` and review `artifacts/performance-budget.json`.
