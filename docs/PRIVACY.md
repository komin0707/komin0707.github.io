# Privacy and Data Protection

Vent Simulator 2D is a static educational simulator.

## Data Collection

The app does not require accounts, backend storage, or patient identifiers. Production Vercel deployments load Vercel Analytics and Speed Insights for aggregate usage and performance telemetry; local previews and non-Vercel hosts skip those scripts.

## Protected Health Information

Do not enter real patient data. The simulator is not intended to collect, store, transmit, or process PHI.

## GDPR

The app has no account, form, or patient-data collection path. Analytics configuration must remain aggregate-only, and release owners must verify consent, deletion, and export obligations for the deployment jurisdiction before public release.

## Cookies

The application code does not set cookies.
